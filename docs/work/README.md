# Work

One file per work item: `NNNN-short-slug.md`, copied from `_template.md`. This is where plans,
decisions and status live, so design docs can stay present-tense.

## Rules

- Create an item for anything spanning more than one sitting or more than one service.
- Update **Status** and **Log** as you go, not at the end. A session that stops mid-task must leave
  the item resumable by someone with no context.
- Decisions that change a boundary also update `docs/architecture.md`.
- When done, set status `done`. Items are never deleted.
